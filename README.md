🌿 VitaminD - AI-Powered Healthcare App

VitaminD is an intelligent healthcare assistant that leverages deep learning and AI to provide early predictions of lung diseases such as COVID-19, Pneumonia, and Normal conditions using chest X-rays. In addition to disease detection, the app offers a Prescription Scanner for digitizing medical prescriptions and a Chatbot to assist users with medical queries. The platform is designed with an interactive and responsive UI for an engaging user experience.

🚀 Features

🫁 Lung Disease Prediction
Predicts COVID-19, Pneumonia, or Normal conditions from chest X-ray images.
Built with a Convolutional Neural Network (CNN) trained on curated medical datasets.
High accuracy with real-time image classification support.

📄 Prescription Scanner
Uses Optical Character Recognition (OCR) to extract and digitize handwritten or printed medical prescriptions.
Outputs structured medicine and dosage data for patient convenience.

💬 AI Chatbot
Provides conversational support for common health-related queries.
Built using natural language processing (NLP) and integrated with a custom medical knowledge base.
Empathetic and context-aware interactions.
